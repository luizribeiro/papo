# papo conformance tests

Each live scenario is an ordinary Rust test generated by its `#[scenario(...)]` attribute. To add
one, write a documented async scenario function with its requirements and `covers` checklist ids;
the attribute is its only registration.

Run every scenario against the default Ergo profile:

```console
cargo test -p papo-conformance
```

Choose one of the configured server profiles with `PAPO_TEST_PROFILE`:

```console
PAPO_TEST_PROFILE=solanum cargo test -p papo-conformance
```

Pass a normal libtest filter to run one scenario:

```console
cargo test -p papo-conformance -- quit
```

Regenerate the six-profile support matrix with:

```console
scripts/conformance-matrix
```

The stable test harness has no runtime-ignore result. A scenario whose requirements or local setup
are unavailable therefore returns success and prints one `ignored` status record with its reason;
matrix generation renders that status as skipped. Passing scenarios, known failures, unexpected
passes, and ordinary failures likewise print exactly one status record. An unexpected pass fails
the test so its stale `known-failures` entry must be removed.
