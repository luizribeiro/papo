# IRCv3 support

Generated by `scripts/ircv3-support`; do not edit by hand.

`Yes` is enabled by default. `Opt-in` needs `enable(Feature::…)`, a builder setting, or a cargo feature. `Unstable` also needs the `unstable` crate feature.

## Stability

Ratified IRCv3 specifications and drafts published on ircv3.net are part of papo's stable API. Open proposals (IRCv3 pull requests) and vendor extensions are behind the `unstable` cargo feature and outside semver. papo accepts both the draft and final capability names, so a draft's ratification does not change the API. An extension leaves `unstable` once it is published on ircv3.net.
